# Doge Dragon Quest 🐶🐉

A polished, offline-first 2.5D action-adventure Progressive Web App.

## Run locally

Because service workers require a secure context, use a local web server instead of opening `index.html` directly.

Examples:

```bash
python -m http.server 8080
```

Then open:

`http://localhost:8080`

## GitHub Pages

Upload the contents of this folder to a repository and enable **Settings → Pages → Deploy from branch**.

The app is designed to run from a relative path, so it works on GitHub Pages project URLs.

## Features

- Installable PWA
- Offline caching
- 8 levels
- 3 worlds/themes
- Classic Doge, Dragon, Explorer and Magic Doge
- Dragon transformation
- Fire breath and charged fireball
- Melee attack
- Coins, score, health and power-ups
- Checkpoints
- Enemies and bosses
- Local save
- Mobile touch controls
- Desktop keyboard controls
- Settings and install button
- No external API required

## Controls

Desktop:
- A/D or Arrow keys: move
- Space/W/Up: jump
- J/Z: melee
- K/X: fire
- Esc: pause

Mobile:
- On-screen buttons
